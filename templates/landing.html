MemTrace Launch demo

Trace. Prove. Quarantine.

MemTrace is a forensic layer for AI agent memory, built on FalkorDB. It finds the memory that changed your agent's behavior, proves it by replay, and quarantines everything derived from it.

Launch live demo

How it works

01

Detect drift

Compare routing decisions before and after a time window. A shift in gateway share is the signal that something in memory changed agent behavior.

02

Trace the culprit

Walk RETRIEVED_IN edges backward from drifted decisions to find which memories were active in those tasks.

03

Prove by replay

Re-run the same tasks with suspect memories hidden. Count how many decisions change outcome. Correlation becomes causal evidence.

04

Compute blast radius

Follow all DERIVED_FROM edges from the root source. Every downstream summary and consolidation is in scope.

05

Quarantine & replay

Mark every node in the blast radius quarantined. Replay with clean memory only and verify routing returns to baseline.
